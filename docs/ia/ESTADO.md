# ESTADO DEL PROYECTO: Maker3D (Diseño e Impresión 3D)

**Última actualización:** 08/11/2026
**Responsable:** MaikikiaM / Antigravity AI

## 1. Misión y Alcance
Monorrepo de modelado geométrico, diseño paramétrico en Python y manufactura aditiva FDM. Orientado a cosplays de alta fidelidad, accesorios cotidianos, juegos de mesa y visualización 3D interactiva en web y móvil.

## 2. Proyectos y Estructura
- `Casco-Clon-Fase-2/`: Casco de Comandante Thorn de Fase 2. Archivos base, cortes milimétricos para Bambu Lab, refuerzos y scripts en `desarrollo-scratch/`.
- `Funda-Lapiz-Xiaomi/`: Estuche protector para Xiaomi Smart Pen de 2ª generación con cierre magnético y soporte de bobina.
- `Figuras-Poliedros/`: Colección geométrica de poliedros regulares y estrellados.
- `Tableros-Catan/`: Loseta de montaña 3D con relieve alpino realista (estilo Matterhorn y Tetons) y `pipeline-montana/`.
- `Visores-HTML/`: Galería web y visores 3D autónomos ligeros Three.js optimizados para pantallas táctiles móviles.
- `registro.txt`: Historial técnico unificado de diseño y fabricación.

## 3. Estado Operativo
- Todos los scripts Python generadores paramétricos consolidados.
